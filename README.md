## Run Locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Create a public repository named `nathanieldarius.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment and visit `https://nathanieldarius.github.io`.
